# YOUYOU远程 · Nintendo Switch

在 Switch 上远程使用 Windows 电脑：用原生界面选择电脑、调整串流画质，通过手柄、键鼠映射或触屏操作桌面和游戏。

本项目是基于 [Antman2023/UURemote-ns](https://github.com/Antman2023/UURemote-ns) 的非官方适配分支，连接电脑端官方 UU远程。采用原生应用界面，不依赖 WebView。源码沿用 [GPL-3.0-or-later](LICENSE)。

## 可以做什么

- 扫码、短信登录；保存本地会话，手动刷新电脑列表。
- H.264、实验性 H.265；NVDEC 硬件解码、Deko3D NV12 显示与映射缓存。
- RTP/RTX 组帧、补包和参考帧恢复；接收、解码、显示分别统计。
- 调整画质档位、分辨率、目标帧率、播放缓冲、垂直同步及声音。
- 两套键鼠映射；实验性 Xbox 手柄直连与按位置/按字母映射。
- 原生菜单触屏、手机式鼠标手势，以及实验性原生多点触控。
- Windows 快捷操作、网络详情和可开关的紧凑常驻网络信息。

H.265、GPU 显示和播放调度已有多轮真机改善反馈。**在线调 FPS 完全不重连、原生 IPv6、TURN TCP/TLS 实际互通、多点触控的全面兼容性仍未完成或未充分验证。** Lite 与标准机的解码耗时差异也没有结案。见[功能状态表](docs/project-status.md)。

## 快速使用

1. 在 Windows 电脑上登录官方 UU远程，保持电脑在线。
2. 在可运行 homebrew 的 Switch 上，以完整应用模式启动程序。使用 hbmenu 时通常按住 **R** 启动游戏进入，避免相册小程序模式。
3. 初次启动扫码或短信登录，与电脑使用同一账号；已有有效会话时直接进入电脑列表。
4. 刷新、选择在线电脑，进入桌面。
5. 串流中 **长按 −** 切换键鼠/手柄模式；**＋** 在键鼠模式按一下打开菜单，在手柄模式长按打开菜单。
6. 结束时通过菜单退出串流；需要解除本地登录时再退出账号。

新配置默认：**720p、60 FPS、高清、垂直同步开启、播放缓冲 8 ms、键鼠方案一**。升级保留已有设置，不会强行覆盖成这些默认值。没有保存过编码选择时使用 H.264。

## 安装与数据

程序仍使用 `switch/UURemote-ns/UURemote-ns.nro` 路径，显示名称改变不要求重建配对。更新前退出程序并备份原文件，保留配置目录；不要为了更新应用格式化 SD 卡或删除存档。

本次文档不附带本地 NRO/NSP。构建需要的本地材料及依赖见[构建说明](docs/build-v52.md)。会话、密钥、账号配置和原始诊断日志不属于公开发布内容；反馈问题前应脱敏。
