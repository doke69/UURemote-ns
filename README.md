## 功能

- 扫码／短信登录、设备列表、登录会话本地保存、退出账号清理。
- H.264／实验性 H.265、NVDEC、Deko3D NV12 直接导入及映射缓存。
- RTP/RTX 组帧、补包、反馈、播放队列及帧率分别统计。
- 画质档位、目标帧率、分辨率、码率、缓冲、垂直同步设置。
- 原生菜单、手柄／键鼠模式、Xbox 字母／位置映射、长按−切换。
- 手机式触屏鼠标／触摸板及实验性原生多点触控。
- 详细网络页、常驻数据浮层、可选局域网诊断回传。

## 状态必须区分

H.265 和 GPU 显示路径已有此前版本真机反馈；不能由此推定所有主机、场景稳定。v52 的多点触控及新手柄行为仍需专项真机验证。在线更改 FPS 仍观察到回退重连。TURN TCP/TLS 适配已编入，但未验证真实中继互通。Switch 原生 IPv6 尚未接通。详见验证表。

## 运行

需要可运行 homebrew 的 Switch，使用完整内存 hbmenu 模式（按 R 启动游戏进入），电脑保持官方 UU远程在线。配置目录为 `sdmc:/switch/UURemote-ns/`。本地菜单 A 确认、B 返回；串流中可长按−切换输入模式，其他设置通过菜单操作。不要沿用上游旧版本“−直接断开”的说明。

本提交不提供包含本地签名材料的 NRO/NSP，也不发布账号缓存、配对配置、日志、参考 APK 或固件。自行构建见文档；不要求升级／格式化系统或清理存档。

## 登录保存与隐私

应用会将会话保存在 SD 的 `session.json`。这是本地可读文件，FAT 上的权限位不等于系统密钥库保护。退出账号会删除缓存。公开反馈前需脱敏；不要提交整个 SD 目录、session、signing.key、telemetry.ini 或原始内存转储。
